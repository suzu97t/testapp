# 段取り

ローカルで使う、プロジェクトマネジメントと要件定義のサポートツール。
人は「判断」だけを行い、整理と点検は道具に任せる、という考え方で作っています。

設計の根拠と今後の予定は [PLAN.md](PLAN.md) にあります。

## 使い方

Node.js 22.13 以上が必要です。インストールするものはありません。

```sh
npm start        # http://127.0.0.1:4321/ が開く
```

1. プロジェクトの名前を入れる
2. 画面上の欄に、思いついたこと・聞いたこと・頼まれたことを1行で書く（議事録の貼り付けも可）
3. 受付箱で「これは何か」を1つ選ぶ
4. あとはホームの「今日やること」（最大3件）に従う

データは `data/dandori.db`（SQLite）に入ります。外部には何も送りません。

## コマンドライン

コーディングエージェントからも同じデータを読み書きできます。出力は JSON です。

```sh
./bin/dandori.js help
./bin/dandori.js add "売上の計上先はどちらか？" --type open --owner 社長 --due 2027-08-31
./bin/dandori.js list --type open
./bin/dandori.js next
```

`--ai` を付けて足したものは「AIの案」として記録され、人が画面で確認するまで決定扱いになりません。

## テスト

```sh
npm test         # ルールとデータ層
npm run e2e      # 実ブラウザで初見シナリオ（Playwright が入っている環境のみ）
```

## いま入っているもの

- 受付箱（1行入力、貼り付けの自動分割、文面からの種類の推測）
- 台帳：まだ決まっていないこと／決めたこと／起きたら困ること／言葉／依頼
- 憲章：目的、ゴールの置き方、やらないこと、誰が何を決めるか、立ち止まる条件
- ホームの「今日やること」
- すべての変更の履歴

要件定義の本体（層の整理、曖昧な言葉の点検、受け入れ条件、例外さがし）は次の版です。
